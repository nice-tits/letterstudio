# Letter Studio — business file system

Operator books live here. Product code stays in `../src`. Secrets stay in the tiny-tits vault, not in this tree.

| Path | What |
|------|------|
| `legal/` | Obligations, affiliate rules, what the live site must match |
| `books/` | Chart of accounts + ledger (cash, not GAAP theater) |
| `crm/` | Buyer list (email + sku + date). No letter bodies. |
| `competitors/` | Dossier (team fills) |
| `marketing/` | Plan + drafts (team fills) |
| `seo/` | Status notes |
| `ops/` | How we run the box |
